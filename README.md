# Loan Risk & Approval Analytics Dashboard

Interactive Power BI dashboard for analyzing loan approvals, risk levels, customer financial behavior, and lending performance using advanced visual analytics and KPIs.

## Overview

This project contains a Power BI dashboard focused on loan risk and approval analytics. It helps analyze applicant profiles, credit risk patterns, approval decisions, financial behavior, and lending performance indicators through interactive visuals and KPI-driven reporting.

## Dashboard Focus Areas

- Loan approval and rejection analysis
- Customer credit risk segmentation
- Applicant income and loan amount behavior
- Financial and demographic risk indicators
- Lending performance KPIs
- Interactive Power BI visualizations

## Project Files

- `Loan Risk & Approval Analytics Dashboard.pbix` - Main Power BI dashboard file
- `credit_risk_dataset.csv` - Dataset used for the dashboard

## How To Use

1. Download or clone this repository.
2. Open `Loan Risk & Approval Analytics Dashboard.pbix` in Microsoft Power BI Desktop.
3. If needed, update the dataset path to `credit_risk_dataset.csv`.
4. Refresh the report data.
5. Explore dashboard pages, slicers, filters, and KPI visuals.

## How To Edit

To customize the dashboard:

1. Open the `.pbix` file in Power BI Desktop.
2. Use **Transform data** to edit Power Query steps or update the CSV source path.
3. Use **Model view** to review relationships and table structure.
4. Use **Measure tools** to edit or add DAX measures.
5. Use **Report view** to customize visuals, filters, slicers, and page layout.
6. Save the `.pbix` file and commit the updated version to Git.
